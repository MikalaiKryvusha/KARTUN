## Цель

**Achieve.** Выпустить KARTUN 1.0: подписанный APK на GitHub Releases, который ставится на Android 16+ и проходит
весь путь пользователя из `GOAL.md` (выбрать фото → улучшить нейросетью на устройстве → сравнить «до/после» → сохранить
или поделиться), с заказом владельца: много входных форматов, PNG/JPEG/WebP на выходе, «Поделиться», ссылка из буфера,
ползунок «до/после», 10 языков, каталог моделей.

## Критерии приёмки

1. Релизная сборка подписана ключом из `.env`. Проверка: `apksigner verify --print-certs app-release.apk` печатает
   `CN=Mikalai Kryvusha, O=KARTUN, C=BY`.
2. Подписанный релиз (`com.kriniks.kartun`) пройден на Титане пользовательским путём, все случаи — `pass`. Проверка:
   отчёт `testcases/reports/<дата>_release_1_0_titan.md`.
3. Каждый входной формат из списка ниже открывается в KARTUN на Титане. Проверка: тот же отчёт, строка на формат.
4. Открытых случаев в `testcases/TC_F2_guarded_loop_device_backlog.md` нет (каждый `pass`, `fail` с багом или
   `skipped` с причиной).
5. README (EN и RU) показывает экраны текущей сборки и версию 1.0; руководство в приложении — с картинками.
6. `versionName = "1.0"`, релиз `models` на GitHub закреплён.
